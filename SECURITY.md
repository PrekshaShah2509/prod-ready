# Security policy

## Supported versions

Security fixes are considered for the latest `0.x` release line. The current release is `0.1.0`.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues. Send a concise report to [prekshashah.consult@gmail.com](mailto:prekshashah.consult@gmail.com), including impact, reproduction guidance, and affected version. Do not include unnecessary proprietary source code or live secrets.

The maintainer will acknowledge reports, assess impact, and coordinate disclosure. Avoid public disclosure of a suspected vulnerability before responsible disclosure is coordinated.

Because this is a local CLI, analysis reports and source code are not transmitted by the tool itself.
