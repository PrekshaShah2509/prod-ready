# Support

- **Bugs:** use GitHub Issues and the bug-report form.
- **Feature requests:** use the feature-request form.
- **Questions:** use GitHub Discussions if the maintainer enables it; otherwise use a GitHub Issue with clear context.
- **Security issues:** follow [SECURITY.md](SECURITY.md), not public issues.

Please do not post secrets, credentials, private keys, or proprietary source code in support requests.
