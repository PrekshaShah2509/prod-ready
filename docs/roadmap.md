# Roadmap

## V1

Local CLI scanning for Node/TypeScript, PHP/Laravel, React/Next, generic production-risk rules, Git and dependency structure analysis, configuration, ignore files, CI-friendly exits, and terminal/JSON/Markdown/HTML reporting.

## V1.1

Python, Django, FastAPI, richer dependency analysis, additional architecture signals, and deeper monorepo support.

## V1.2

Historical report snapshots, explicit PR-range diff analysis, a richer baseline workflow, and machine-readable new-versus-existing findings.

## V2

Optional hosted dashboards, team policies, organization rules, custom-rule marketplace, and an opt-in AI explanation layer.
