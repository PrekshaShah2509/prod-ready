# Production Readiness CLI

## Category

Developer tooling / static analysis / engineering productivity.

## Target user

Software engineering teams and technical leaders.

## Core problem

Teams need a practical local assessment of production risks across code, configuration, dependencies, and repository history.

## Value proposition

Analyze a repository locally and receive evidence-backed production-risk findings without uploading source code or requiring an AI service.

## Differentiator

Deterministic rules combine framework awareness, dependency structure, Git history, and architecture hotspots rather than duplicating a conventional linter.

## Business model

The initial version is open-source/free. Possible future work includes pro rules, team policies, historical analysis, a hosted dashboard, and custom rules. None are included in V1.
